## How we check facts

1. Every claim in the script is matched to at least one source before the video is made.
2. News is checked on the day of recording; the date is written in each file.
3. Examples and analogies in the videos (for example, Chintu the robot cook) are our own illustrations, and are marked as such.
4. Found a mistake? Open an issue in this repository and we will correct the video description.
